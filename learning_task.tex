\label{sec:learning-task}
Our two transformer architectures are trained in a supervised manner on traces drawn from instances $P=\langle M,O,I,G\rangle$ of a \strips model $M=\langle\mathcal{P},A\rangle$, containing ground actions obtained by instantiating schemas in $A$ on $O$. Object sets $O$ vary across instances.
After training, \strips models can be extracted from the transformers and used for planning. We consider two settings, according to the available supervision.

Under \emph{applicability supervision}, a trace contains an initial state $s_0=I$ and a sequence $\tau=(a_0,\ldots,a_{n-1})$ of applicable and inapplicable domain actions. Each action $a_i$ receives label $0$ if it is applicable in the state reached from $s_0$ by the preceding applicable actions, and $1$ otherwise. We treat inapplicable actions as no-ops and mask them from subsequent attention. We use only the LS Transformer in this setting, since model extraction from the LB Transformer is not possible under this supervision, as explained later.

The transformer predicts a label for each action: $0$ if all its preconditions hold in the state reached from $s_0$ by the preceding applicable actions, and $1$ otherwise. Under \emph{final-state supervision}, a trace contains an initial state $s_0$, an applicable action sequence, and a set $Q_F$ of ground-atom queries about the resulting state $s_F$. Each query $q\in Q_F$ receives label $0$ if $q\in s_F$ and $1$ otherwise. Both the LS and LB Transformers are trained in this setting. Neither setting reveals intermediate states.

Each trace includes ten ground atoms sampled uniformly from all possible ground atoms over $O$, including both true and false atoms in $s_F$. Given $s_0$ and the action sequence, the transformer predicts whether each sampled atom holds in $s_F$. Neither supervision setting provides intermediate states.

We encode $s_0$ using an \texttt{init-start} action followed by an \texttt{init-}$p(\mathbf{o})$ action for each atom $p(\mathbf{o})\in s_0$. The first initializes all ground atoms to false, while each \texttt{init-}$p(\mathbf{o})$ action sets $p(\mathbf{o})$ to true. A query $p(\mathbf{o})\in Q_F$ is encoded as a
\texttt{goal-}$p(\mathbf{o})$ action whose precondition is $p(\mathbf{o})$ and which has no effects.
The initial-state and query actions are shuffled independently within their groups.

Each atom $p(o_1,\ldots,o_r)\in s_0$ is encoded as $\texttt{init-}p(o_1,\ldots,o_r)$ before the domain actions, with an additional $\texttt{init-start}$ action before all of them. Similarly, for each predicate queried in the final state, we introduce a schema $\texttt{goal-}p$ of the same arity. Each sampled atom $p(o_1,\ldots,o_r)$, whether true or false, is represented by a $\texttt{goal-}p(o_1,\ldots,o_r)$ action after the sequence of domain actions, labeled $0$ if it holds in $s_F$ and $1$ otherwise. The $\texttt{init-}p$ and $\texttt{goal-}p$ actions are shuffled within their respective groups.

In both settings, training minimizes focal loss~\citep{lin2017focal}, a variant of binary cross-entropy, over the relevant action labels: applicability of domain actions in the first setting, and truth value of queried final-state atoms in the second.
