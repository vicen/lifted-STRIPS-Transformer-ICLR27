\label{sec:learning-task}
Consider an unknown lifted \strips{} model $M=\langle\mathcal{P},A\rangle$ and problem instances $P=\langle M,O,I,G\rangle$, whose object sets $O$ may vary. Our two transformer architectures are trained in a supervised manner on traces drawn from these instances, containing ground actions obtained by instantiating schemas in $A$ on $O$. After training, \strips{} models can be extracted from the transformers and used for planning. We consider two settings, according to the available supervision.

Under \emph{applicability supervision}, each trace contains an initial state $s_0=I$ and a sequence $\tau=(a_0,\ldots,a_{n-1})$ of applicable and inapplicable domain actions, with no subsequent states observed. The transformer predicts a label for each action: $0$ if all its preconditions hold in the state reached from $s_0$ by the preceding applicable actions, and $1$ otherwise. Inapplicable actions are masked when predicting subsequent labels, so they do not affect later predictions. We train only the LS Transformer in this setting, since model extraction from the LB Transformer is not possible under this supervision, as explained later.

Under \emph{final-state supervision}, each trace contains an initial state $s_0$, a sequence of applicable domain actions, and the resulting final state $s_F$. Both the LS and LB Transformers are trained in this setting. Each trace includes ten ground atoms sampled uniformly from all possible ground atoms over $O$, including both true and false atoms in $s_F$. Given $s_0$ and the action sequence, the transformer predicts whether each sampled atom holds in $s_F$. Neither supervision setting provides intermediate states.

Initial and final states are encoded using auxiliary actions. For each predicate $p$ that may appear in an initial state, we introduce an action schema $\texttt{init-}p$ with the same arity. Each atom $p(o_1,\ldots,o_r)\in s_0$ is encoded as $\texttt{init-}p(o_1,\ldots,o_r)$ before the domain actions,
with an additional $\texttt{init-start}$ action before all of them.
Similarly, for each predicate queried in the final state, we introduce a schema $\texttt{goal-}p$ of the same arity. Each sampled atom $p(o_1,\ldots,o_r)$, whether true or false, is represented by a $\texttt{goal-}p(o_1,\ldots,o_r)$ action after the sequence of domain actions, labeled with its truth value in $s_F$. The $\texttt{init-}p$ and $\texttt{goal-}p$ actions are shuffled within their respective groups.

In both settings, training minimizes focal loss~\cite{lin2017focal}, a variant of binary cross-entropy, over the relevant action labels: applicability of domain actions in the first setting, and truth value of queried final-state atoms in the second.
